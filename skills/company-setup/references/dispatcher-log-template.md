# Dispatcher log template

Save as a Google Doc named "<Owner> – Dispatcher log" (for example "IT/AI – Dispatcher log") in the company folder. The dispatcher adds one entry per run; the owning department reads it for health checks.

---

# {{log_owner}} – Dispatcher log

One entry per run of the daily hand-off dispatcher for {{company}}, newest first. Each entry lists the work list, rows worked with their status change, new hand-offs, rows left for the next run, stale Waiting rows, the end-of-run check results and any errors. The Company Brief stays the record of the work itself; this log records what the automation did.
